# AzurLaneData

Contains extracted JSON data from Azur Lane.

Data is extracted using the [Fernando2603/AzurLaneDataExtractor](https://github.com/Fernando2603/AzurLaneDataExtractor) project.

> [!NOTE]
> sharecfgdata files are extracted through key matching rather than full Lua-to-JSON conversion. As a result, when the game introduces new fields, they will not appear in the generated JSON until the extraction schema has been updated.

You can view the current extraction schemas [here](https://github.com/Fernando2603/AzurLaneDataExtractor/tree/main/src/schema)
